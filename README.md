# kuyrukhane

A self-hosted family library app. Track your household's book collection, scan ISBNs, and share books across family members.

## Features

- **Book management** — add, edit, delete, and search books by title, author, or ISBN
- **ISBN scanner** — scan a barcode with your phone camera and import book details automatically from Open Library
- **Household sharing** — create a household, invite family members with a code, and share one book collection
- **Authentication** — email verification, httpOnly cookie sessions, account lockout after failed attempts, password reset via email
- **PWA** — installable on mobile, works offline for browsing

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | ASP.NET Core 10 minimal API |
| Database | PostgreSQL 17 + EF Core 10 |
| Frontend | React 19 + Vite 8 |
| Auth | JWT in httpOnly cookie (BCrypt passwords) |
| Email | MailKit (SMTP) |
| Containerisation | Docker + Docker Compose |

## Local Development

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- [Node.js 22](https://nodejs.org)
- [PostgreSQL 17](https://www.postgresql.org/download/) — or just use Docker Compose (see below)

### Run with Docker Compose (easiest)

```bash
cp .env.example .env
# Fill in .env — at minimum set POSTGRES_PASSWORD, JWT_KEY, and the email fields
docker compose up --build
```

App is available at `http://localhost:8080`.

### Run without Docker

**1. Start a local PostgreSQL instance** and create a database named `library`.

**2. Configure secrets** (do not put secrets in appsettings.json):

```bash
cd kuyrukhane
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Database=library;Username=postgres;Password=yourpassword"
dotnet user-secrets set "Jwt:Key" "your-secret-key-at-least-32-chars"
dotnet user-secrets set "Email:From" "you@example.com"
dotnet user-secrets set "Email:Smtp:Host" "smtp.gmail.com"
dotnet user-secrets set "Email:Smtp:Username" "you@gmail.com"
dotnet user-secrets set "Email:Smtp:Password" "your-app-password"
```

**3. Start the backend:**

```bash
dotnet run --launch-profile http
# API available at http://localhost:5254
```

**4. Start the frontend:**

```bash
cd frontend
npm install
npm run dev
# Dev server at http://localhost:5173 (proxies API calls to :5254)
```

### Database migrations

EF Core migrations run automatically on startup. To add a new migration after changing models:

```bash
dotnet ef migrations add YourMigrationName
```

## Deploying to Render

The repo includes `render.yaml` for one-click deployment.

**Steps:**

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → **New** → **Blueprint** → connect your repo
3. Render reads `render.yaml` and creates the web service + PostgreSQL database
4. After the first deploy, open the web service → **Environment** and fill in:

| Variable | Example value |
|---|---|
| `APP_BASE_URL` | `https://kuyrukhane.onrender.com` |
| `APP_HOST` | `kuyrukhane.onrender.com` |
| `Email__From` | `noreply@yourdomain.com` |
| `Email__Smtp__Host` | `smtp.gmail.com` |
| `Email__Smtp__Username` | `you@gmail.com` |
| `Email__Smtp__Password` | your Gmail app password |

`JWT_KEY` is auto-generated by Render — you do not need to set it.

5. Trigger a redeploy after setting the variables.

> **Note:** Render's free web service tier spins down after 15 minutes of inactivity (cold start ~30 s). Upgrade to the Starter plan ($7/mo) for always-on.

## Environment Variables Reference

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Render only | Injected automatically by Render |
| `ConnectionStrings__DefaultConnection` | Docker / local | Npgsql connection string |
| `Jwt__Key` | Yes | JWT signing secret, min 32 chars |
| `App__BaseUrl` | Yes | Public URL used in email links |
| `ASPNETCORE_AllowedHosts` | Production | Hostname(s) the server accepts, e.g. `yourdomain.com` |
| `Email__From` | Yes | Sender address |
| `Email__FromName` | No | Sender display name (default: `Family Library`) |
| `Email__Smtp__Host` | Yes | SMTP hostname |
| `Email__Smtp__Port` | No | SMTP port (default: `587`) |
| `Email__Smtp__Username` | Yes | SMTP username |
| `Email__Smtp__Password` | Yes | SMTP password / app password |

## API

A sample request file is at [`library.http`](library.http) — open it in VS Code with the REST Client extension or in JetBrains IDEs.

Key endpoints:

```
POST /register        { name, email, password }
POST /login           { name, password, rememberMe }
POST /logout
GET  /me

GET  /books           ?search=&page=&pageSize=&available=
POST /books           { title, author, isbn }
POST /books/import/{isbn}   auto-import from Open Library

POST /household       { name }
GET  /household
POST /household/join  { code }
POST /household/invite
```

All authenticated endpoints use the httpOnly `auth` cookie set on login — no Authorization header needed.
